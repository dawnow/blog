> 在自己的互聯網棲息之地留存一些東西。

![](https://i.loli.net/2019/10/10/tzIMKEOyxjFhkXB.jpg)

互聯網在給我們普通人帶來方便的同時最大的一個作用是什麼呢？我覺得是「留存」。

個人也是歷史的一部分，在互聯網世界中數據庫和服務器就像是我們保存歷史片段的「櫃子」，這些櫃子在當前看來可能作用並不大，它就放在那裏，但試想五十年過後，它沒有突然消失也沒有被 Delete，還存在於千里之外的服務器裏面，我們仍然能夠通過互聯網訪問並看到這些東西，那這些東西就變得更加珍貴，同時這些虛擬的文件也是歷史變遷的見證者。（這點是石國鵬老師給我的啓發）

在二〇一六年十一月二十七日發佈我的第一篇微信推文。已經過去這麼長時間了，但是我的惰性使我並沒有發佈幾篇文章，還好微信官方還保留着我的賬號，時間過得很快，留下的東西就變得很珍貴，快餐文化當道的時代似乎已經沒有人在沒有任何經濟效益的情況下堅持着自己的創作了。這一點都不奇怪，畢竟生存才是第一位的，但以最低的成本在互聯網上面進行創作並留存也是可能的，這正是我今後要做的事情。

今年年中開始，我在 WordPress.com 上面搭建了一個自己的動態博客網站併發布了一些內容，但是免費用户的頁面會被官方加上他們自己的廣告，當然還有其他種種的限制，付費即可消除大部分限制，但對於我這種的非商業性質的博客來説，一旦付費，之後的每個月份或者年份都必須續訂（個人套餐為 456 港幣／年），否則官方就會刪除該賬號的所有內容，因此我一直停留在免費套餐，這樣最起碼官方不會突然就刪除你的賬號，可以待之後有商業性方面的打算後再升級站點，之前的內容也會得到保留，所以這是我目前的一個想法。（搭建博客的最初想法是源於王躍琨）

近來我去參加了一個互聯網公司的面試，雖然沒有被錄取，但是也得到一些啓發和感想。我是一個特別注重.. 原創性.. 的人，那天面試那位 HR 問我做數碼評測最注重什麼，我回答説「原創性」吧，然後就沒回音了，當然沒有被選中跟很多因素有關，但還是要從自身找原因，畢竟一個公司的價值觀哪有那麼輕易改變。隨後呢我就把我很久都沒有發過文章的公眾號翻了出來，換上新頭像，換上新名字，準備在以後跟自己的博客同步發佈一些各種各樣的內容，不光是科技相關的東西。

前些天我在 bilibili 用户 [Happyaddone](https://space.bilibili.com/6971044/) 那裏看到了他藉助 GitHub page 和一款擁有圖形界面的靜態博客寫作工具 Gridea 搭建了自己的靜態博客，我也嘗試搞了一個，雖然這個過程遇到了一些小問題，但沒有太多技術含量，所以很快就搭建完成並把原來的 WordPress 上面的內容遷移了過來，但是在測試的時候發現訪問速度和加載速度非常不理想，而且我的圖片直接從本地上傳後會在源文件夾生成緩存文件，關鍵是這些文件還不能移動或刪除，其次還有 Markdown 一些語法不支持等，我放棄了這玩意。隨後我在 bilibili 看到了 [Master lisa](https://space.bilibili.com/100518197/) 藉助 GitHub Page 與 Hexo 搭建個人靜態博客的視頻，三集視頻看完之後，我就準備開始了，這玩意自定義程度太高了，同樣也需要一定的動手能力，經過我兩天的摸索和折騰，最終還是建好了，之後我把 WordPress 上的文章再次遷移過來了，同時我還藉助 LeanCloud 安裝了 Valine 評論系統以便讓瀏覽者在文章下方免登錄就可以留言評論。再後來我就在阿里雲挑選了一個域名並把原來的 GitHub 域名自定義到我新買的域名，這樣一來，這個靜態博客就達到基本的標準了。（感謝 [Happyaddone](https://space.bilibili.com/6971044/) 以及 [lisa](https://space.bilibili.com/100518197/)，感謝 Hexo、Valine 和 Google）
